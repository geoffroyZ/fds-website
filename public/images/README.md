# Images pour le site FDS

Ce dossier contient toutes les images utilisées sur le site web de FDS - Full Digital Solution.

## Structure des dossiers

### `/hero/`
Images pour la section hero de la page d'accueil :
- `digital-transformation.jpg` - Image de fond pour la transformation digitale
- `web-development.jpg` - Miniature pour le développement web
- `mobile-app.jpg` - Miniature pour les applications mobiles
- `digital-strategy.jpg` - Miniature pour la stratégie digitale

### `/services/`
Images pour chaque service (nommées selon l'ID du service) :
- `1.jpg` - Développement Web
- `2.jpg` - Applications Mobiles
- `3.jpg` - E-commerce
- `4.jpg` - SEO & Marketing Digital
- `5.jpg` - Consulting Digital
- `6.jpg` - Maintenance & Support

### `/about/`
Images pour la page À propos :
- `team-hero.jpg` - Image de fond pour la section hero
- `office-workspace.jpg` - Espace de travail/bureau

### `/portfolio/`
Images pour les projets du portfolio :
- `ecommerce-platform.jpg` - Plateforme e-commerce
- `mobile-banking.jpg` - Application mobile bancaire
- `corporate-website.jpg` - Site web corporatif

## Recommandations

- Dimensions recommandées : 1920x1080px pour les images hero
- Format : JPG ou WebP pour un bon équilibre qualité/poids
- Compression optimisée pour le web
- Noms des fichiers en kebab-case
- Images pertinentes par rapport au contexte burkinabé/africain quand possible
